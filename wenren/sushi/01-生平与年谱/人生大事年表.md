# 苏轼人生大事年表

> 公元 1037-1101

> 第三版（C 档复核重建）：多关键词共现定位 + ±400 字上下文抽读验证



## 眉山少年 1037-1056

- **1037 景祐三年十二月十九** · 0岁 · 眉州眉山 · *家庭*
  苏轼生于四川眉州眉山城内纱縠行苏宅，父苏洵年二十七，母程氏。 〔人物：苏洵、程夫人、苏辙〕
  〔来源：李一冰 p38 / 王水照崔铭 p20 / 林语堂 p26〕

- **1039 宝元二年** · 2岁 · 眉州眉山 · *家庭*
  苏辙生于眉山，自此兄弟情好终生。 〔人物：苏辙、苏洵、程夫人〕
  〔来源：李一冰 p38 / 王水照崔铭 p20 / 林语堂 p26〕

- **1040 宝元三年** · 3岁 · 眉州眉山 · *家庭*
  苏轼兄弟并从父苏洵、伯父苏涣学；苏家于眉山家境渐窘。 〔人物：苏洵、苏涣〕
  〔来源：李一冰 p38 / 王水照崔铭 p20 / 林语堂 p26〕

- **1042 庆历二年** · 5岁 · 眉州眉山 · *家庭*
  程夫人亲授苏轼兄弟读《汉书》，讲范滂气节，奠定苏轼一生节义根基。 〔人物：程夫人〕
  〔来源：王水照崔铭 p24〕

- **1043 庆历三年** · 6岁 · 眉州眉山 · *创作*
  苏轼在眉山读《后汉书》《旧唐书》；并开始学作诗文。
  〔来源：李一冰 p38 / 王水照崔铭 p20 / 林语堂 p26〕

- **1045 庆历五年** · 8岁 · 眉州眉山 · *交游*
  苏轼兄弟随父苏洵游学本地，熟读经史；苏洵游学四方，未仕。 〔人物：苏洵〕
  〔来源：王水照崔铭 p24〕

- **1046 庆历六年** · 9岁 · 眉州→成都 · *仕途*
  苏洵携轼、辙赴成都参加秋试，苏轼兄弟未中。 〔人物：苏洵〕
  〔来源：李一冰 p63〕

- **1047 庆历七年** · 10岁 · 眉州眉山 · *创作*
  苏洵游学归来，督教二子；苏轼兄弟始作策论，论古今治乱。 〔人物：苏洵〕
  〔来源：王水照崔铭 p24〕

- **1048 庆历八年** · 11岁 · 眉州眉山 · *交游*
  苏轼入天庆观北极院从道士张易简读书，前后三年；同学有陈太初。 〔人物：张易简、陈太初〕
  〔来源：李一冰 p49 / 王水照崔铭 p161 / 林语堂 p224〕

- **1049 皇祐元年** · 12岁 · 眉州眉山 · *创作*
  苏轼于天庆观读书期间与同学陈太初游岷江；作诗咏叹蜀中山水。 〔人物：陈太初〕
  〔来源：李一冰 p49 / 王水照崔铭 p161 / 林语堂 p224〕

- **1051 皇祐三年** · 14岁 · 眉州眉山 · *交游*
  苏轼游学彭山仙女坪、寿昌院；与刘仲达、刘微之、史炤等本地友朋交往。 〔人物：刘仲达、刘微之〕
  〔来源：李一冰 p49 / 王水照崔铭 p161 / 林语堂 p224〕

- **1052 皇祐四年** · 15岁 · 眉州眉山 · *创作*
  苏轼于彭山游寿昌院；与史炤、刘仲达等结伴咏诗。 〔人物：史炤、刘仲达〕
  〔来源：李一冰 p49 / 王水照崔铭 p161 / 林语堂 p224〕

- **1054 至和元年** · 17岁 · 眉州眉山 · *家庭*
  苏轼十八岁，娶眉山青神县乡贡进士王方之女王弗为妻；王弗敏而静，识人甚明。 〔人物：王弗〕
  〔来源：模型知识〕

- **1055 至和二年** · 18岁 · 眉州→京师 · *仕途*
  苏洵携苏轼、苏辙乘舟东行入京应举；途经成都，谒见雅州知州张方平，张方平荐之于欧阳修。 〔人物：苏洵、张方平〕
  〔来源：李一冰 p63〕

- **1056 嘉祐元年** · 19岁 · 成都→京师 · *交游*
  父子抵京师；苏洵以书谒欧阳修，欧阳修读《机权》《衡论》《权书》诸文大器重之。 〔人物：苏洵、欧阳修〕
  〔来源：李一冰 p63 / 朱刚 p175〕

- **1040 宝元三年** · 3岁 · 眉州眉山 · *家庭*
  苏轼兄弟并从父苏洵、伯父苏涣学；苏家于眉山家境渐窘。 〔人物：苏洵、苏涣〕
  〔来源：李一冰 p38 / 王水照崔铭 p20 / 林语堂 p26〕

- **1053 皇祐五年至和元年** · 16岁 · 眉州眉山 · *仕途*
  苏洵游学在外，作《上欧阳内翰书》求谒；苏轼居家并备考。 〔人物：苏洵、欧阳修〕
  〔来源：李一冰 p63 / 朱刚 p175〕


## 进士与凤翔 1057-1065

- **1057 嘉祐二年正月** · 20岁 · 京师开封 · *仕途*
  苏轼、苏辙同科进士及第；苏轼应《刑赏忠厚之至论》获主考官欧阳修激赏；欧阳修语梅尧臣：'取轼冠多士，愧老夫当避路。' 〔作品：刑赏忠厚之至论〕 〔人物：欧阳修、梅尧臣、苏辙〕
  〔来源：李一冰 p1075 / 李一冰 p63 / 朱刚 p175〕

- **1057 嘉祐二年四月** · 20岁 · 京师 · *家庭*
  苏轼母程夫人卒于京师；父子仓促扶柩归眉山。 〔人物：程夫人〕
  〔来源：模型知识〕

- **1058 嘉祐三年** · 21岁 · 眉州 · *创作*
  苏轼居眉山守制；研读《论语》《孟子》；与王弗于乡。 〔人物：王弗〕
  〔来源：模型知识〕

- **1059 嘉祐四年** · 22岁 · 眉州→京师 · *创作*
  苏轼服除，父子再赴京师；途经忠州，登白帝城，俯瞰瞿塘峡；至京师。 〔人物：苏洵〕
  〔来源：李一冰 p63〕

- **1060 嘉祐五年** · 23岁 · 京师 · *仕途*
  苏辙亦在朝；兄弟与曾巩、晁端友等交往；授苏轼河南府福昌县主簿，未赴。 〔人物：曾巩、苏辙〕
  〔来源：李一冰 p63 / 朱刚 p175〕

- **1061 嘉祐六年八月** · 24岁 · 京师→凤翔 · *仕途*
  苏轼应制科入第三等'贤良方正能直言极谏科'；授大理评事、签书凤翔府判官；十一月与苏辙别于郑州，作《和子由渑池怀旧》。 〔作品：和子由渑池怀旧〕 〔人物：苏辙〕
  〔来源：李一冰 p97 / 王水照崔铭 p35 / 林语堂 p69〕

- **1062 嘉祐七年** · 25岁 · 凤翔 · *创作*
  苏轼到凤翔任签判；与王弗同赴；判案明断；作《凤翔八观》《李太白仙诗卷后》等诗。 〔作品：凤翔八观、李太白仙诗卷后〕 〔人物：王弗、陈公弼〕
  〔来源：王水照崔铭 p40〕

- **1063 嘉祐八年** · 26岁 · 凤翔 · *仕途*
  英宗即位；苏轼上书论政；与凤翔知府陈公弼交往有诗；作《陈公弼传》。 〔人物：陈公弼、英宗〕
  〔来源：李一冰 p112 / 王水照崔铭 p48〕

- **1064 治平元年** · 27岁 · 凤翔 · *交游*
  苏轼于凤翔度岁；与陈公弼交往；与苏辙书信论学不断；作《和子由渑池怀旧》新韵。 〔人物：陈公弼、苏辙〕
  〔来源：李一冰 p97 / 王水照崔铭 p35 / 林语堂 p69〕

- **1065 治平二年** · 28岁 · 凤翔→京师 · *家庭*
  凤翔任满返京；五月王弗卒于京师，年二十七；遗孤苏迈年十一。 〔人物：王弗、苏迈〕
  〔来源：李一冰 p122〕

- **1060 嘉祐五年** · 23岁 · 京师 · *交游*
  王安石回京任三司度支判官；与苏轼、曾巩、吕公著等交往；议论新法雏形。 〔人物：王安石、曾巩、吕公著〕
  〔来源：李一冰 p63 / 朱刚 p175〕

- **1063 嘉祐八年** · 26岁 · 凤翔 · *仕途*
  英宗即位大赦；苏轼被任命为登闻鼓院直鼓院。 〔人物：英宗〕
  〔来源：李一冰 p112 / 王水照崔铭 p48〕


## 熙宁还朝与外任 1068-1078

- **1068 熙宁元年** · 31岁 · 京师 · *仕途*
  服除返京；苏轼授官告院签书判官；与王安石初次接触。 〔人物：王安石〕
  〔来源：王水照崔铭 p49〕

- **1069 熙宁二年** · 32岁 · 京师 · *仕途*
  王安石拜参知政事，推行新法；苏轼上书论新法不便，主张'补外'。 〔人物：王安石〕
  〔来源：王水照崔铭 p49〕

- **1070 熙宁三年** · 33岁 · 京师 · *仕途*
  苏轼连上《议学校贡举状》《拟进士对御试策》，力陈科举之弊；王安石深忌之。 〔作品：拟进士对御试策〕 〔人物：王安石〕
  〔来源：李一冰 p1075〕

- **1071 熙宁四年** · 34岁 · 京师→杭州 · *仕途*
  苏轼上书神宗论新法'求治太速，进人太锐，听言太广'；请外任；通判杭州。 〔人物：神宗、王安石〕
  〔来源：李一冰 p167 / 王水照崔铭 p5 / 朱刚 p95〕

- **1072 熙宁五年** · 35岁 · 杭州 · *创作*
  苏轼通判杭州，与周邠、鲁有开、刘述等游西湖；主持修缮钱塘六井；作《饮湖上初晴后雨》。 〔作品：饮湖上初晴后雨〕 〔人物：周邠、鲁有开〕
  〔来源：王水照崔铭 p73 / 朱刚 p137〕

- **1073 熙宁六年** · 36岁 · 杭州 · *家庭*
  通判杭州任内赈济浙西灾荒；与王闰之（王弗堂妹）成婚。 〔人物：王闰之〕
  〔来源：李一冰 p1076 / 王水照崔铭 p66〕

- **1073 熙宁六年（续）** · 36岁 · 杭州 · *交游*
  苏轼通判任上，曾润色闽中诗僧谦师诗；与欧阳修再会于京师书信中。 〔人物：欧阳修〕
  〔来源：李一冰 p1076 / 王水照崔铭 p66〕

- **1074 熙宁七年** · 37岁 · 杭州→密州 · *仕途*
  由杭州移知密州；九月赴任，访润州金山寺作《游金山寺》；到密州后捕蝗抗灾。 〔作品：游金山寺〕
  〔来源：李一冰 p243 / 王水照崔铭 p105 / 朱刚 p113 / 李一冰 p232 / 王水照崔铭 p5〕

- **1075 熙宁八年** · 38岁 · 密州 · *创作*
  苏轼知密州；整军治蝗；中秋怀苏辙，作《水调歌头·明月几时有》；作《江城子·密州出猎》。 〔作品：水调歌头·明月几时有、江城子·密州出猎〕 〔人物：苏辙〕
  〔来源：李一冰 p253 / 王水照崔铭 p90 / 朱刚 p130 / 李一冰 p243 / 王水照崔铭 p105 / 朱刚 p113〕

- **1076 熙宁九年** · 39岁 · 密州 · *创作*
  苏轼修葺超然台，作《超然台记》；与刘恕交往论学。 〔作品：超然台记〕 〔人物：刘恕〕
  〔来源：李一冰 p20 / 王水照崔铭 p223〕

- **1077 熙宁十年** · 40岁 · 密州→徐州 · *仕途*
  由密州移知徐州；七月黄河决口于澶渊，苏轼亲率军民筑堤抗洪七十余日。
  〔来源：李一冰 p203 / 王水照崔铭 p194 / 林语堂 p9〕

- **1078 元丰元年** · 41岁 · 徐州 · *创作*
  徐州市政渐安；苏轼建黄楼以镇水；与苏辙相聚百日；作《黄楼赋》。 〔作品：黄楼赋〕 〔人物：苏辙、王巩〕
  〔来源：李一冰 p20 / 王水照崔铭 p110 / 朱刚 p311〕

- **1078 元丰二年正月** · 41岁 · 徐州 · *交游*
  苏轼在徐州市政渐安；上书神宗荐刘攽等人才；与苏辙、王巩、文同等交往。 〔人物：苏辙、王巩、刘攽〕
  〔来源：李一冰 p20 / 王水照崔铭 p110 / 朱刚 p311 / 李一冰 p204 / 王水照崔铭 p121 / 林语堂 p190〕

- **1070 熙宁三年（续）** · 33岁 · 京师 · *仕途*
  苏轼为《王莽传》论，引发政敌不满；与范镇论政不合。 〔人物：范镇〕
  〔来源：王水照崔铭 p49〕

- **1074 熙宁七年** · 37岁 · 杭州 · *交游*
  苏轼于杭州任上，赏识画家文同（与可）之画，与文同订交。 〔人物：文同〕
  〔来源：李一冰 p243 / 王水照崔铭 p105 / 朱刚 p113〕

- **1076 熙宁九年（续）** · 39岁 · 密州 · *创作*
  苏轼修葺超然台；作《望江南·超然台作》。 〔作品：望江南·超然台作〕
  〔来源：李一冰 p20 / 王水照崔铭 p223〕

- **1077 熙宁十年** · 40岁 · 密州 · *创作*
  苏轼于密州与苏辙书信中讨论诗学；自言'诗以奇趣为宗，反常合道为趣'。 〔人物：苏辙〕
  〔来源：李一冰 p20 / 王水照崔铭 p223〕


## 乌台诗案 1079

- **1079 元丰二年七月** · 42岁 · 湖州 · *仕途*
  苏轼到湖州任仅三月，监察御史里行何正臣、舒亶、李定等交章弹劾苏轼诗文'愚弄朝廷'、'指斥乘舆'；诏追摄赴御史台狱。 〔人物：何正臣、舒亶、李定〕
  〔来源：李一冰 p307 / 王水照崔铭 p124 / 朱刚 p78〕

- **1079 元丰二年七月二十八日** · 42岁 · 湖州→京师 · *贬谪*
  苏轼被拘，自湖州启程赴京；途中闻诸弟、子由恐受牵连，'魂飞汤火命如丝'。 〔人物：苏辙〕
  〔来源：李一冰 p312 / 王水照崔铭 p133 / 朱刚 p287〕

- **1079 元丰二年八月十八日** · 42岁 · 京师御史台狱 · *贬谪*
  苏轼入御史台狱，史称'乌台诗案'。下狱四十三日，讯问二十余次。 〔人物：神宗、李定〕
  〔来源：李一冰 p312 / 王水照崔铭 p133 / 朱刚 p287〕

- **1079 元丰二年八月** · 42岁 · 京师御史台狱 · *贬谪*
  王安石虽已罢相，闻讯上书神宗'安有圣世而杀才士者乎'；苏辙乞纳官赎兄罪，贬筠州酒监。 〔人物：王安石、苏辙、神宗〕
  〔来源：模型知识〕

- **1079 元丰二年十一月** · 42岁 · 京师御史台狱 · *贬谪*
  御史台定谳：苏轼贬检校水部员外郎、黄州团练副使，本州安置，不得签书公事；神宗从轻发落。 〔人物：神宗〕
  〔来源：李一冰 p335 / 王水照崔铭 p136 / 朱刚 p17〕

- **1079 元丰二年十二月底** · 42岁 · 京师→黄州 · *贬谪*
  苏轼出狱，责授黄州团练副使；长子苏迈随行；与王闰之及家人赴贬所；岁暮抵陈州，与苏辙相见。 〔人物：苏辙、王闰之、苏迈〕
  〔来源：李一冰 p21 / 王水照崔铭 p6〕


## 黄州岁月 1080-1084

- **1080 元丰三年二月一日** · 43岁 · 黄州 · *创作*
  苏轼抵黄州，初寓定惠院；后迁临皋亭；作《初到黄州》。 〔作品：初到黄州〕
  〔来源：李一冰 p345 / 王水照崔铭 p140 / 林语堂 p200〕

- **1080 元丰三年三月七日** · 43岁 · 黄州 · *创作*
  沙湖道中遇雨，作《定风波·莫听穿林打叶声》；同行者相顾狼狈，苏轼已不觉。 〔作品：定风波·莫听穿林打叶声〕
  〔来源：李一冰 p345 / 王水照崔铭 p140 / 林语堂 p200〕

- **1080 元丰三年** · 43岁 · 黄州 · *其他*
